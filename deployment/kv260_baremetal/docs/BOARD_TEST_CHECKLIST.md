# KV260 board test checklist

- [ ] KV260 powered
- [ ] USB/JTAG detected
- [ ] Correct board mode selected
- [ ] Correct XSA selected
- [ ] Bitstream included in XSA/platform
- [ ] Platform built
- [ ] Accelerator generated driver found
- [ ] Application built
- [ ] FPGA programmed
- [ ] Cortex-A53 processor initialized
- [ ] Input cache flushed
- [ ] Output cache invalidated
- [ ] Accelerator completed before timeout
- [ ] Non-zero logits returned
- [ ] Class matched fixed-point reference
- [ ] Latency captured
- [ ] UART, platform, and result screenshots saved
