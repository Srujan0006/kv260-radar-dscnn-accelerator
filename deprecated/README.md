## Warning about the legacy trainers

The window-split trainers above must not be used for reported results:
their random `make_splits` puts windows from the same radar recording in
both train and test sets (recording-level data leakage). Any accuracy
they produce is optimistic. The recordwise pipeline asserts
train/val/test recordings are disjoint.
