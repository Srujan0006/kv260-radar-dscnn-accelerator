# Deployment

## Custom HLS accelerator: bare-metal benchmark

The package is in [`7_deployment/kv260_baremetal/`](../7_deployment/kv260_baremetal/):

- `src/`, `include/`: Cortex-A53 standalone app. It allocates aligned DDR buffers,
  does cache flush and invalidate, starts the accelerator, polls for done, checks
  the logits bit for bit against the fixed-point reference, then runs 10 warm-up
  and 100 timed iterations.
- `driver/radar_cnn_stream_full_v1_0/`: driver generated by Vitis HLS 2022.2
  for the packaged IP.
- `docs/`: Vitis GUI setup, board checklist and troubleshooting.

Steps:

1. Create a Vitis platform from `6_hardware/vivado/optimized/v3_wrapper.xsa`
   (`psu_cortexa53_0`, standalone).
2. Fill in `include/radar_driver_binding.h` from the generated driver. It stops
   with `#error` until you do.
3. Build, open a serial terminal at 115200-8N1 on the second enumerated port,
   and run over JTAG.

Pass criterion: all four Q6.10 logits are bit-identical to the reference, and
the predicted class matches. Expected accelerator-only time is ≈ 1.16 ms.

## Vitis AI DPU path

```bash
python 5_quantization/quantize_vai.py --help    # Vitis AI 3.5 container
bash 5_quantization/compile_kv260.sh
python scripts/run_kv260_vart.py --help         # on the board
```

The compiled model in `outputs/real/compiled_kv260_dpu/` is the plain
`Radar2DCNN` baseline (see [architecture.md](architecture.md)).
